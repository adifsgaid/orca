Prototype for Orca

Resume on Account Switch

When Orca switches your Claude (or Codex) account, should agents that are already running follow it, the way claude-swap moves everything at once? Orca can't swap the login under a running agent, but it can reopen the agent with --resume on the new account: same conversation, a 2-3 second blink. This page lets you feel the rules for when that happens. Pick a walkthrough on the left, or poke the buttons yourself.

Each pane on the right has its own buttons: send a message, let the turn end, ask permission, leave text unsent.

The rules this page runs

  1. A pane is behind when its account isn't the one selected for its provider. Switching back makes it current again, so nothing moves.
  2. A behind pane moves only when it's idle at the prompt. Thinking, or asking you for permission, counts as busy: it moves once that turn ends.
  3. Unsent text in the prompt holds the move, so it can't eat what you were typing.
  4. No session id (status hooks off) means it can't reopen that conversation, so it stays put. It's never restarted blank.
  5. "Ask me" works like Codex's prompt today: you approve once, then each pane moves when it's idle.
  6. Claude and Codex are independent: switching one never touches the other's panes.

Assumes Orca records which account each Claude pane started on (it already does for Codex), and that it can tell when a prompt holds unsent text. Both are open questions.
